# PSet 1 — Python solutions (hetmacro)

Problem set 1 solutions using `hetmacro`: quadrature, Broyden, Nelder-Mead, two-period labor supply, portfolio choice.

## Layout

- **notebooks/** — Jupyter notebooks for each problem (`pset1_problem1.ipynb` … `pset1_problem5.ipynb`).
- **report/** — Report PDF (`pset1_report.pdf`) and figures.

## Running the notebooks

1. From the repo root, create/activate a Python environment and install dependencies (`requirements.txt`).
2. Notebooks auto-detect the repo root; run from any directory or open `notebooks/` in Jupyter.
3. Run notebooks in order (problem 1 through 5).
